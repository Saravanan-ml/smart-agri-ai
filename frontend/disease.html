📁 CNN Deep Learning Architecture Specification

This module is designed for 224x224 RGB image tensors processed through convolutional feature extractors (Conv2D, MaxPooling2D, Dropout, Dense Softmax) using TensorFlow/Keras. When real plant disease image datasets (such as PlantVillage) are placed in data/disease_dataset/, executing python backend/training/train_disease_model.py automatically trains and deploys the weights to backend/models/disease_model.h5.
